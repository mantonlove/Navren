# Navren 向量数据适配与验收

日期：2026-10-10。范围：公共原文的本地表示、索引更新及检索提供端。公共数据适配实现与隔离库验收通过，最新双模型复查 PASS；当前运行服务与真实云端答复尚未验收。完整结果见 `outputs/vector-data-adaptation/report.md`。

## 输入到证据的路径

已登记官方公共原件 → 固定解析器 → 原文跨度与产品／份额／渠道绑定 → 受信准入 → 封存公共快照 → 确定性检索表示 → 本地 q8 BGE 编码 → SQLite 派生向量 → 固定快照的原文、时间、许可与图门核验 → 向量＋FTS5 融合 → 原文 resolver → 现有云端交流链。

表示与向量都留在本地，读路径不下载模型、不调用 embedding API；表示不能代替证据。云端最终读取的引文仍是 canonical 原文，不把加在表示里的字段标签当作原文新增句子。此轮没有改动私人库、收益计算、Agent、TTS、界面或部署入口。

## 三类资料的适配

| 类型 | 确定性表示 | 边界 |
|---|---|---|
| 微众渠道披露 JSONP | 官网中文字段名、不可变文档标题、渠道披露代码、原始单字段 JSON 引文 | 必须匹配来源、parser、shape、channel、product 和定位；不认证底层基金／份额映射 |
| 官方市场完整原文 | 不可变标题＋原文片段 | 保留原语种；不通过云端翻译或生成摘要来扩充索引 |
| 经核对 PDF 原文跨度 | 不可变标题＋已准入原文 | 原有页码、字符范围、份额和图出处保持；不自动解读表格、费档或条件 |

字段白名单为 code/name/saleStatus/type/placement/saleType/risk/publish/investor/charge/chargeWay/customerGroupType。中文名称取自官网字段表，`investor` 的“合理投资范围”只是检索标签，不能据此证明用户已获得投资资格。

仅完整、规范且定位匹配的单字段 JSON 加中文标签。未知字段、错误来源、截断或跨字段片段保留原文表示，不推断语义标签；原件准入合同仍独立拦截 schema 漂移。“详见产品页面”“详见产品页”“以保险公司核定为准”标记为需其他资料，保持原值，不补费率或免费结论。这个标记属于索引构建诊断，不是新增的最终回答裁决器。

净值、收益率、分红、拆分与交易序列继续走有身份、日期、单位和来源约束的结构化查询及确定性计算。账户、资产、聊天和画像不进入公共向量库。

## 更新、复用与固定快照

输入政策 `public-vector-documents/2` 与完整编码文本共同纳入 `text_sha256`。标签或表示政策改变后，旧派生索引明确失效、回退 FTS5，重建时不能误复用旧表示。权威原文和封存快照无需改写。

微众原件是整份目录，任一行或资料日期改变都会改变原件摘要，进而使每个新版引用获得新 ID。本次改为：同一模型 profile、同一表示 hash，可以从最近最多 8 个完整校验通过的索引复用数学向量；新版成员仍绑定新版引用，不继承旧证据的权限、时效或图。每个引用的完整窗口来自同一个已验证引用，不能拼接不同历史窗口。仅保存目标版本需要的复用向量，找到所需表示后停止历史扫描。

自动 `preserve_current` 发布剔除已到达确认替代日期的旧文档版本，保留其他文档与未来才被替代的版本，防止高频更新把当前成员不断堆高。已封存的旧发布、引文、图和向量不修改；历史查询使用原固定代次。重复旧缓存读不会覆盖新当前版。直接手动历史发布的行为保持独立。

提交前再次核验原件、许可和超时；提交向量与索引清单是同一事务。读侧仍重新核验全部快照成员与向量 hash，并在原文／身份／时间／图约束过滤之后进行近邻排序。`retrieval.vector_used` 表示本次是否确实有向量候选，避免把分支可用误解成语义贡献。

## 验收资料与复现

1. 微众：`outputs/official-discovery-audit-20261009/catalog-original.jsonp`，资料日期 2026-09-30；选取 6 个跨类型渠道披露对象。以资料日期做历史检索，另验证截至 2026-10-10 已超过费用、风险等 7 天新鲜度；销售披露不证明即时可买。完整 13,660 产品约 16 万字段超过单代 5,000 片段上限，本次不做全量容量验收。
2. PDF：只读备份 `outputs/window-progress/rag/reviewed-public.sqlite3`，6 份官方 PDF、22 个页内引用；沿用执行前冻结的 `manual-question-set.json` 12 题，不改原件预期。原核对由 Codex 与独立代理完成，不能称银行工作人员签核。
3. 市场：只读备份上轮实际公共库的验收副本，52 个文档版本、282 片段；英文 ECB 原件题及中文跨语探针。小样本不证明全面跨语检索质量。
4. 合成更新／故障：固定向量替身与临时 SQLite，用来验证一个字段更新的复用量、当前成员不累积、历史快照、错字段／身份、旧政策、损坏缓存和历史扫描上限。它们不作为真实语义效果证据。

真实模型验收脚本：

```sh
NAVREN_VECTOR_ENABLED=0 .venv/bin/python scripts/verify_vector_data_adaptation.py --out outputs/vector-data-adaptation/data-acceptance.json
PYTHONPATH=.:tests NAVREN_VECTOR_ENABLED=0 .venv/bin/python -m unittest tests.test_vector_data_adaptation tests.test_local_vector_retrieval
```

对照单列 FTS、原 title＋excerpt 表示、字段适配后的直接向量与混合结果。明确身份和不明确身份分别报告，字段题不给 facet 补召回；不根据实测结果修改题集、阈值或模型。PDF 的旧 FTS 已能覆盖 12 题，因此该题集只能验证本轮不退化和出处保持，不能夸为向量提高正确率。

出网检验是在验收 Python 进程拦截 socket connect/connect_ex，并统计调用；不等同操作系统全网抓包。无本轮真实云端金融答复、用户资产配置或银行规模并发验收；运行服务是否采用这份新源码与依赖，需要集成窗口按冻结版本单独验证。

## 本轮实测与复查结果

181项既有回归＋19项新风险测试通过；真实官方原件隔离库21项边界强门通过。微众6对象×5模板化字段题，直接向量Top-3从旧20/30提高至30/30，混合从17/30提高至26/30，仍有4个字段遗漏；混合Top-1为12/30，不把直接向量结果冒充最终排序结果。PDF混合保持12/12，直接向量Top-3完整覆盖8/12。英文ECB探针通过；中文ECB探针最终混合未找到目标原文，跨语尚未达标。

单字段合成更新测试：新版12个引用全部变更，只重编码1个、复用11个，连续10次更新当前成员不增长且历史固定快照可回查。真实资料验收全过程29.215秒，进程峰值约379MB十进制；本进程查询出网尝试0次、云模型调用0次。计时含多个对照及原文核验，不是单次用户请求基准。

实际Aiping渠道 DeepSeek-V4.1-Flash 与 GLM-5.3-Flash 同包独立审核均PASS。首轮DeepSeek长度截断，保持包不变提高上限，仅续审失败侧取得合法PASS；GLM原结论复用。两者认可字段/引用绑定、时效门、增量复用和快照修复，未发现阻断问题，但未独立执行测试、核验原件或重算摘要。未送审的大原件、完整结果与送审设计快照在本地产物目录回查。

新增发布的实际成员必须通过来源状态与许可门；无可用成员报 empty_release，部分明确成员不可用报 unavailable_release_member，事务不提交。已在当前发布的纯重复请求保持无操作；读侧依旧核验来源许可，不因缓存恢复使用权。向量search失败按白名单reason回退FTS5，status检查也有明确reason；诊断不回显查询、异常正文或私人路径。
