## 用户认可的五类工具

| 能力 | 接入方向 | 功能与边界 |
| --- | --- | --- |
| 银行业务 | 自建 Navren Bank MCP，复用现有模拟银行 | 查询账户、账单、持仓、卡片、代扣；准备转账、申购等草案；读取执行回执。用户确认、权限、金额、适当性、幂等和执行状态由银行底座控制。 |
| 金融证据 | 自建证据 MCP，复用资讯和公共 RAG | 查询权威文字报道、产品说明、费用和赎回条款。返回原文链接、发布时间、资料版本和证据。历史净值和公开资料不证明当前渠道可买。 |
| 用户记忆与日历 | 将已有能力接入工具服务 | 按具体问题读取相关收支、目标、家庭责任和偏好，查询近期安排，返回可交互日历和图表数据。个人数据按账户隔离并遵循记忆授权。 |
| 文档处理 | Microsoft MarkItDown CLI 或 MCP | 提取 PDF、Word、Excel 等文件中的文字。账单金额、表格结构另用结构化解析与核对处理，转换文本不能直接认定为已核验财务数据。 |
| 财务计算 | 自建受限 Navren 财务 CLI | 十年数据批量分析、现金流缺口、资金安排比较、资产配置情景和报告。输出口径、依据和图表数据。高频查询继续复用现有函数，避免每次查询都启动独立进程。 |

工具类别不对应固定 Agent 数量，也不要求每类部署一个独立服务进程。

## 候选第三方组件

- Microsoft MarkItDown：优先评估普通文档转换；无需增加模型。
- AKShare：补充公开基金历史净值、分红等数据，按需要封装接口并保留真实来源；不是微众银行交易或在售资格接口。
- Playwright MCP：按需用于必须通过网页交互获取的公开资料和服务查询；普通采集优先直接 HTTP/API。
- MCP 官方 Python SDK：用于 Navren MCP 客户端、服务端与协议适配。

## 展示方向

示例问题：“下个月要进货，还要交房租，我还能拿多少钱理财？”
