# Navren 银行卡片样式与切换效果定稿

样式确认日期：2026-10-06。归档确认日期：2026-10-07。

用户已确认单张卡片、多卡堆叠样式及点击切换效果，并明确要求“没问题，存档”。本目录作为后续接入账户页的设计与交互定稿保留。

## 已认可的样式

- 卡片水平摆放，保持真实银行卡的比例和圆角。
- 银行品牌色衍生渐变：中行红、建行蓝、农行绿；页面切换深浅外观时，卡片自身配色保持不变。
- 使用贴合卡片轮廓的细窄侧边和柔和投影，保留轻微厚度。
- 16位卡号，每4位一组；前12位用星号隐藏，例如 `**** **** **** 0826`。
- 大额数字表示卡内现金余额；下方数字表示关联持仓的投入本金，不包含上方现金。演示金额不代表实际账户数据。
- 单张展示完整卡片；多张绑定时堆叠展示，后排露出银行名称和尾号。
