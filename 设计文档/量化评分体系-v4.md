# Navren量化评分体系 v4.0

> 历史设计或实施记录：保留文内注明版本的测试结论，不能作为当前版本的验收结果。当前实现与运行方式见 [README](../README.md) 和 [技术说明](../TECHNICAL.md)。本机机器信息已清理，未发布的历史产物不提供仓库链接。

> 理论框架：RAGAS（RAG 评估） + FINRA 2026 监管报告 + CFA Institute 适当性准则
> 评分方式：每题关联自动化测试脚本，0/1 客观计分，禁止主观打分
> 目标：均分 ≥ 92，最低单项 ≥ 85

## 参考权威来源

| 来源 | 应用维度 |
|------|---------|
| RAGAS (2024) — Faithfulness, Answer Relevancy, Context Precision, Context Recall | 生成质量、检索质量 |
| FINRA 2026 Regulatory Oversight Report §GenAI | 准确性、合规性、日志审计、人工监督 |
| FINRA Rule 2111 (Suitability) | 适当性管理 |
| CFA Institute Standards of Practice | 推荐解释性、利益冲突披露 |
| SEC Reg BI (Regulation Best Interest) | 推荐冲突管理 |

## 一、生成忠实度（Faithfulness，权重 15%）

> 来源：RAGAS Faithfulness metric。回答中的每个事实声明必须可从检索到的上下文中验证。

| # | 指标 | 测试方法 | 阈值 |
|---|------|---------|:--:|
| 1.1 | 产品名准确率 | 20 条推荐回复中产品名全部来自检索结果 | 100% |
| 1.2 | 收益率准确率 | 回复中的"业绩比较基准"数字与产品 JSON 一致 | 100% |
| 1.3 | 风险等级准确率 | 回复中的 R1-R5 标注与产品 JSON 一致 | 100% |
| 1.4 | 无幻觉产品 | 未检索到的产品名不出现在回复中 | 100% |
| 1.5 | 事实可溯源 | 每句声明可追溯到知识库或合规模板 | 90% |

**测试脚本**：`tests/v4/test_faithfulness.py`
- 对 20 条回复做结构化事实提取 → 与 products.json 逐字段比对

## 二、合规适当性（Suitability，权重 20%）

> 来源：FINRA Rule 2111 + SEC Reg BI。推荐必须与客户风险承受能力匹配。

| # | 指标 | 测试方法 | 阈值 |
|---|------|---------|:--:|
| 2.1 | 风险等级约束 | R2 用户的所有推荐产品 ≤ R3（15 组画像测试） | 100% |
| 2.2 | 起购金额约束 | 推荐产品的起购金额 ≤ 用户可投金额 | 100% |
| 2.3 | 封闭期约束 | 推荐产品的封闭期 ≤ 用户投资期限 | 100% |
| 2.4 | 禁止承诺收益 | 20 条推荐回复中不出现"保本""保证收益"等 13 类违禁词 | 100% |
| 2.5 | 替代路径提供 | 合规拒绝时间时给出替代方案（大额存单/存款等） | 100% |

**测试脚本**：`tests/v4/test_suitability.py`
- 15 组画像 × 推荐 → 每个推荐产品检查 3 项约束

## 三、检索质量（Retrieval Quality，权重 15%）

> 来源：RAGAS Context Precision + Context Recall。

| # | 指标 | 测试方法 | 阈值 |
|---|------|---------|:--:|
| 3.1 | Context Precision | 检索结果中相关产品排在前列（10 组查询，Precision@3 ≥ 80%） | ≥ 80% |
| 3.2 | Context Recall | 所有适格产品中至少有 1 只出现在检索结果中 | ≥ 90% |
| 3.3 | 检索延迟 | 5 层过滤 < 50ms（100 次测试 P99） | < 50ms |
| 3.4 | 去重有效性 | 同产品族去重率（10 组测试，无重复变体） | 100% |
| 3.5 | 结果多样性 | 检索结果的 risk_level 分布 ≥ 2 个不同等级 | ≥ 80% |

**测试脚本**：`tests/v4/test_retrieval.py`
- 10 组画像 × search_products → 逐项检查

## 综合得分

```
总分 = Σ(维度分 × 权重)
维度分 = (通过项数 / 总项数) × 100
```

每项只有 0 或 100 分。维度内取平均。

**执行方式**：`python3 tests/v4/run_all.py` → 输出 `outputs/score-v4.json`

目标：均分 ≥ 92，最低单项 ≥ 85。
