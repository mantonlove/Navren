## 一、已经落地的页面组织

普通主导航统一为 **对话 → 账户 → 发现 → 我的**。桌面为侧栏，小屏为同顺序底部导航。完成初始引导后入口与品牌返回对话；指定对象深链接优先，不自动发送旧 URL 的问题或动作。头部保留当前位置、主题色调节与中文/En 切换；侧栏底部为齿轮图标的“设置”入口。

- **账户**：本金/负债/可安排资金口径，首批最多 6 个资金对象，最多 3 个已知安排；明确转账与财务日历入口。对象、完整日历、流水与报告、全部活动各自进入主内容区。旧表单保留业务处理，不再把 11 个业务区一起铺在首页。
- **发现**：热点封面流 → 整卡周报 → 2—3 个产品预览 → 最近研究备选。研究列表具有筛选、显式比较模式、2—3 款逐行对照；原文、周报、产品和方案均有完整阅读视图。沿用已有市场组件，未改写市场采集模块。
- **我的**：先目标与责任、四域概览及真实待核实条件，再进入目标、图谱、资料、收藏、设置。主题与中文/英文控件位于右上角，模式、字体与语音集中在设置。保存记忆与允许读取是两个不同状态。
- **顾问演示**：从个人入口单独进入，同一服务对象、无额外权限。显示已授权账户简报、当前身份与授权版本匹配的本地交接摘要；日期推进在这里显式勾选确认。

共享模块为 `js/view_context.js`、`js/lifecycle.js` 与 `css/site_workspace.css`。按模块新增 `account_workspace`、`discover_workspace`、`mine_workspace` 控制器和样式，维持现有原生前端技术栈。

## 二、旧功能的实际去向

下表路径相对本地服务，`object_id` 使用实际服务对象 ID。页面跳转本身只读取，不准备或执行金融操作。

| 旧入口 | 现在的实际路径 | 保留的能力及限制 |
|---|---|---|
| 账户 `#overview` | `account.html?view=home` | 服务端本金资产、负债、可安排资金及计算口径；无可靠映射时不称实时市值 |
| `#calendar` | `account.html?view=calendar#calendar` | 月/周/日/议程、独立类型/来源/组合筛选；`calendar-day`、`calendar-item` 完整详情 |
| `#payments` | `account.html?view=payments#payments` | 转账、定时转账、AA；付款账户明确选择，既有确认流程保留 |
| `#cards` | `cards`、`card-detail&object_kind=card&object_id=…` | 卡片列表、申请记录、挂失及卡片控制；无现成卡片时仍有申请入口 |
| `#subscriptions` | `subscriptions`、`subscription-detail` | 商户订阅与银行代扣保持两个对象和两种取消动作 |
| `#wealth` | `holdings`、`holding-detail` | 当前持仓本金、批次、可赎回条件；历史收益进入 `calendar` / `wealth-product`，不与当前现金相加 |
| `#tasks` | `plans`、`plan-detail` | 生活计划、报价、预留、释放、预约及回执沿用原业务流程 |
| `#records` | `activity`、`operation-detail` | 按实际 ID 回看待确认、执行结果、失败、申请及结算状态 |
| `#statements` | `statements` | 流水默认视图、分析子视图、月/年报告、异常/周期候选及 CSV 预览/确认/批次结果 |
| `#archive` | `archive` → `record-detail` | 贷款、存款、目标、服务、授权可定位；借贷/保障执行缺口仍明确只读或未接入 |
| `#public` | `recommend.html?view=research#research` | 官方公开目录与来源、历史披露及真实净值研究；公开资料不具备申购权限 |
| 推荐旧首页 | `recommend.html?view=home` | 用户标签改“发现”，文件兼容保留；热点仍使用已有封面流 |
| 产品/比较 | `view=research`、`product`、`compare` | typed 来源 + ID + 版本引用；未知风险不默认 R3，不按名称映射订单 |
| 周报/报道 | `view=weekly&object_id=期号`、`reading&object_kind=event/article&object_id=…` | 对应版本、事实/分析/条件、证据、原文、历史及收藏 |
| 备选方案 | `view=plans`、`plan&object_kind=research_plan&object_id=…` | 新方案服务端保存；旧浏览器配置只读并标历史身份；实际产品回执覆盖独立统计 |
| 我的 `#graph` | `mine.html?view=graph#graph` | 四域图谱、节点文字、检索、键盘、路径、证据及账户/历史收益回链保留 |
| `#profile` | `view=profile` | 本人确认资料、待核实观察、记忆授权和演示业务配置；本地问卷不冒充正式测评 |
| `#appearance` | `view=settings` | 外观、中文/En、阅读模式、字体、语音和授权统一设置 |
| `#saved` | `view=saved` | 公共收藏、可核验私人收藏及继续阅读；不恢复身份不明的私人正文 |
| 财务目标 | `view=goals`、`goal&object_id=…`、`goal-draft&object_id=…` | 新建/修改/删除均为准备摘要 → 本人确认 → 同 ID 回执；取消独立取得回执 |
| 顾问工作台 | `copilot.html` | 独立“顾问视角 · 演示”，返回原个人视图；非真实银行后台角色 |

`NavrenWorkspace.activate()` 作为旧调用适配层保留。`portfolio/calendar_on`、`graph_view/from/to`、对象 ID/版本和来源参数转译保留；未知视图、删除对象与过期版本有明确返回/重新核对入口，不替换为同名对象。

## 三、跨页、来源及确认合同

1. **提问引用（23:16 用户调整后）**：账户、发现、我的不再挂公共提问框。对象上的“问 Navren”或引用按钮进入聊天，带入可编辑问题/对象引用和返回位置；不自动发送 Agent。跨页草稿通过 `/page-contexts` 随机票据保存，绑定 HttpOnly 会话、工作区、隐私版本和 20 分钟有效期；URL 只有票据。草稿一次领取、不能作为执行票据消费。用户在聊天中点击发送时，以最终文字重新建立一次消费票据并核验对象版本；授权变化后晚到的草稿不得恢复私人文字/引用。

2. **返回**：完整子视图创建历史；初始化才替换。日期、来源、组合、筛选、选中对象、列表/滚动位置及焦点保存在有限视图元数据中。跨页离开保存位置；内部来源页有历史时返回原页；模式切换保存当前视图快照。晚到定位、失败与响应不能盖回更新后的视图。
3. **私人身份**：BankClient 同时核验工作区、隐私版本与请求/视图代次。服务端私人对象响应含身份；保持旧数组形状的接口在可信响应头提供同样边界。授权撤销、跨窗口切换、文件预览晚到与 BFCache 返回均清理或遮蔽旧内容，再重新核对；核验失败有重试入口。
4. **账单来源**：新增 `/reports/snapshot` 以显式 source + source_version 获取完整报告组；整组读取版本一致，不依靠可变 active_source 的标签。报告有显式引用入口；本次 Agent 对话的读取来源/版本单独绑定，不改写工作区默认来源。导入流水不推算银行余额；更换来源或旧版本读取返回冲突。原读取接口仍保持兼容。
5. **日历**：时间、类型、账单来源与组合独立。导入账单 + 历史组合在服务端明确拒绝，不暗换账本。目标截止日从同一目标 ID 投影，没有现金变化、计划扣款或资金预留；独立提醒的修改不修改目标或银行合同。
6. **目标写入**：新增受限 GoalService，期望对象版本、准备幂等键、摘要 digest、明确确认及回执；草案 30 分钟有效。旧版本、旧授权、取消/过期草案不能覆盖；未知结果核查原 ID。沿用既有数据库来源约束，新用户目标在 details 标记 `record_origin=user_entered`，不伪装成第三方银行产品。
7. **研究与执行**：新方案保留每个产品的实际来源/ID/版本、研究假设和创建日期；资料过期与产品执行覆盖分别展示。只有关联到同一银行产品 ID 的成功购买回执才计覆盖；两款中只完成一款为部分覆盖。产品覆盖不能证明假设金额、期限和整个资产配置已实现。只读 `research_plans` Agent 工具已接入，聊天可查同一记录。
8. **金融操作**：保留已有 BankUI 准备、审核、本人确认与操作 ID。关闭视图不取消服务端操作；提交中/结果未知不重建订单。服务端发现实际断连后写入断连审计，已提交结果依旧可按原 ID 查询。没有修改金额计算、模型配置、权限与适当性规则。
9. **旧个人档案**：聊天欢迎语不再通过旧浏览器画像宣称正式测评或已知资产条件；问卷记录单独绑定当前工作区/隐私版本，结果为参考。完成问卷不再自动清空聊天；旧未绑定私人收藏、交接或画像不自动获得新账户权限。
