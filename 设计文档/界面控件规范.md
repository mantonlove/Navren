# 展开菜单与日期时间控件

> 设计与实施记录不代表当前整体已验收；本机原始收据不随仓库发布，当前入口见仓库 README。

所有产品页面加载 `css/form_controls.css`，在头部样式末尾加载 `css/quiet_focus.css`，在页面末尾加载 `js/form_controls.js`。新建业务表单继续使用标准 `select`、`input[type=date]`、`input[type=datetime-local]` 和 `input[type=time]`，共享组件自动增强动态插入的字段；无需逐个复制菜单代码。

展示统一使用现有主题颜色、12px 圆角、细边框、柔和阴影。普通菜单选项约 36px 高，选中项使用浅蓝底与勾选标记；银行卡菜单保留银行名称、卡号尾号与账户余额分层。深色主题和减少动态效果系统设置自动生效。

输入框聚焦不使用蓝色粗描边或光圈，只轻微改变中性边框。键盘操作保留细中性色焦点提示，错误状态继续显示。新界面也遵守这一要求。菜单展开在顶层浮动，不改变表单高度、不挤开后续内容。

原生字段始终是数据来源。保留 `name`、`required`、`min`、`max`、`step`、`disabled`、`readonly`、标签与表单默认值；`FormData`、`reportValidity()`、已有业务监听器和程序读取方式保持原合同。用户确认新值时仅向原字段派发一次 `input` 与一次 `change`，程序赋值不伪造业务事件。字段校验失败定位可见按钮，展示该字段真实的校验错误。

浮层点击外部或按 Escape 收起；方向键、Home/End、Enter/空格与输入字符检索用于选择。日期支持月份/年份跳转、方向键与 PageUp/PageDown，日期时间使用同一面板编辑时分，再按确定写入原字段。关闭浮层不会提前提交尚未确认的日期时间。页面滚动、视图切换、隐私锁定和原控件移除均清理浮层。

月份字段由既有 `NavrenMonthPicker` 管理，共享样式将其外观统一。自动增强不接管 `month`、`multiple` 或 `size>1` 的列表选择；禁止给普通单选增加 `multiple` 来规避统一设计。确有原生控件需求时，给字段或祖先显式添加 `data-navren-control="native"`。

公开接口：

```js
NavrenFormControls.enhance(container); // 立即增强某个容器，通常自动观察已足够
const control = NavrenFormControls.mount(selectOrDateInput);
control?.open();
control?.refresh();
NavrenFormControls.refresh(selectOrDateInput);
NavrenFormControls.close();
NavrenFormControls.destroy(selectOrDateInput); // 临时清理；永久退出需先添加 native 标记
```

设置 `value`、`selectedIndex`、`option.selected`、`valueAsDate` 或 `valueAsNumber` 会同步展示；替换选项或更新约束会自动刷新。其他特殊程序写入若绕过字段属性设置器，应调用 `refresh()`，并由业务决定是否需要派发事件。

此组件只处理交互展示，不调用银行接口，不提交金融操作，不保存账户信息。新增业务菜单先复用此组件；必须采用独立菜单时，仍复用相同颜色、圆角、阴影、焦点、选中标记及关闭规则。
