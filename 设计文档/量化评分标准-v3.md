## 综合得分公式

```
总分 = 智能体×0.15 + RAG×0.10 + 配置×0.15 + 合规×0.15 + 对话×0.15 + 体验×0.10 + 技术×0.10 + 安全性能×0.10
```

## 评分执行

每项指标对应自动化脚本或静态检查规则。评分结果写入 `design/score-v3.json`。

目标：均分 ≥ 92，最低单项 ≥ 85。不达标项自动标记为待修复，修复后重新评分。
