# 聊天图片与语音完整保存

日期：2026-10-16。任务：MEDIA-20261016。用户明确要求补齐原文件保存，并实际确认跨浏览器、重新登录可恢复。沿用已接受的注册用户私有实例，不改变整体未通过状态。

## 目标与边界

- 图片和用户原始录音的 bytes 服务端完整保存，SHA-256 与上传原件相同。助手已经成功生成的朗读音频也保存，不以重新合成代替原音频恢复。
- 同账号同画像跨浏览器、退出重登、清空站点存储及服务重启后，能读完整历史、加载图片并播放音频。
- 不同用户、不同画像、未登录、已撤销会话、被显式删除或隐私撤回的媒体均不可读。不输出静态公开路径、数据库路径、令牌或长期可分享的外链。
- 之前没有上传服务器的旧 bytes 无法凭元信息重建。原浏览器尚有 IndexedDB 录音或聊天 dataURL 时，只在明确的当前用户/画像绑定下迁移；不从无归属旧全局缓存认领。迁移成功必须可核验，不能只改显示文案。
- 本轮不发真实短信、不新增付费模型或语音调用，不开启外部开发复查。复用正式逻辑与隔离短信、ASR/TTS夹具，验证的是持久化与恢复；模型、识别与合成质量不在本轮验收。

## 接口合同要求

- 独立有界二进制上传接口，不能扩大普通 Agent JSON 的1MiB上限。服务端校验当前注册用户/画像、Origin/CSRF、真实文件类型与大小，再生成不可猜测ID。原文件加密保存在私人库，禁止文件名或任意路径决定磁盘位置。
- 前端 Agent 请求只传已上传媒体ID；服务端重查归属、隐私代次与有效性，将真实描述符与用户回合绑定。受理的用户消息和媒体绑定保持一致，助手失败也不删除用户原件。上传失败不能显示为已成功发送。
- 原件描述符包含协议、ID、类型、MIME、bytes、SHA-256、必要的音频时长和存储状态；不接受客户端自报描述符作为授权。旧 `not_archived` 元信息保持只读兼容。
- 图片单独发送、无转写语音均是合法用户消息；允许保存并显示本地说明，不伪造识别文字，不因此触发付费模型。
- 原件读取按当前会话和工作区服务端授权；返回类型固定、nosniff/no-store，不公开文件路径。切号/退出停止播放、撤销Blob URL、阻止迟到文件注入旧视图。
- 助手朗读只从已经批准的回复及有效语音守卫产生的音频保存；不能让浏览器上传一段音频冒充助手已批准输出。历史原音频是只读回放，不恢复金融执行或旧审核票据。
- 普通资料添加、重新登录、常规源码升级不使原媒体丢失；显式删除聊天、隐私撤回按原合同删除/撤回相关媒体。文件缺失或密文/摘要损坏明确报错。
- 数据库、密钥与部署配置可整体迁移到服务器，不能依赖当前浏览器或固定桌面路径。

## 必须交付的实际验收

1. 浏览器A通过真实界面上传图片、录制并发送语音，记录上传bytes摘要；助手生成音频用明确隔离语音提供器通过正式WebSocket和守卫接线。
2. A退出→清空localStorage、sessionStorage、IndexedDB→同账号密码登录，图片实际解码，音频实际播放；不只看HTTP状态。
3. 全新独立浏览器B同账号同画像登录，原件SHA和A上传/服务端生成一致，图片加载且音频播放。
4. 同一数据与密钥重启冻结版服务后，B再次恢复，原件及消息绑定保持。
5. 反例覆盖匿名、其他账号、同用户其他画像、撤销会话、猜ID、删除/隐私撤回、类型伪装、超限及存储破坏；无访问泄露。
6. 保留普通文字、引用、只读历史、安全发布与多用户隔离的有效证据，只复验此次实际影响面。所有结果绑定源码/界面版本、数据和当前入口；本轮未因此宣布原97项整体通过。
