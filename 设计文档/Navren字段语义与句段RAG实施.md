# Navren 字段语义与句段 RAG 实施

> 设计与实施记录不代表当前整体已验收；本机原始收据不随仓库发布，当前入口见仓库 README。

日期：2026-10-11。用户明确要求修复复查指出的问题；当前正在继续实施和复验。历史失败、原问题、原预期和冻结原件保留。结构和重排开关默认关闭，当前不能声称整个 RAG 已验收。

## 当前端到端路径

用户原问题 → 本地身份、时点、权限、产品/份额/渠道和图关系准入 → 字段/角色请求登记 → 原 canonical 词项与向量召回 + 完整句组召回 → 可选本地多问句视图、查询译文 → 完整原句窗口与有界候选池 → 本地小型交叉编码排序 → 不可拆分引文组预算 → 权威原件逐项回查 → 受限语义支持和缺口 → 云端交互。

本轮已实现到知识工具的消费/出站合同。云端最终回答逐事实核验、TTS、浏览器完整链路和实时产品适当性没有在此验收；不能把排序分数当作事实支持。

权威数据仍是公共 SQLite 的原始 document_versions、1000 字 canonical chunks、引文 ID、发布快照和图关系。个人数据库独立，本轮不读取或改写个人库。公共句段、向量与窗口属于可重建派生信息，不重写原件，也不新建常驻服务。

## 已落实的修复

1. 字段与角色缺口贯通真实 KnowledgeRetrieval → CloudDataBoundary。knowledge_semantics.py 只允许固定枚举，支持绑定本次成功消费的公共产品、原字段、发布、文档和版本；消费失败、撤回、错版本或隐藏引文同步使支持失效。未知产品不能凭提供方 metadata 自注册为公共对象，任意问题、路径、字段值和解释不出站。普通缺口与每产品语义缺口分别保留，避免列表截断或去重吞掉后者。
2. 自然完整句成为必要核心，不再让 480 字/1600 字预算切割成为事实边界。长句能够跨预算父段恢复，但必须严格同版本、产品、份额、渠道、页、显式段定位、日期、维度、条件和来源。6400 字/8 个 canonical 引文内恢复不了的核心保留明确拒绝约束，不能退回部分 singleton 绕过完整性。
3. evidence_group_selection.py 以整组支付预算，先满足各必要组和来源/维度要求，再加可选邻句；多个句组共用同一原引文时不复制 rank 配额。轨迹只含公共组 ID、原排名、接受/拒绝固定原因和预算，不记录原问。完整跨度漏列任何重叠 canonical 引文时，即使重排失效也不能接受。
4. canonical_sentence_window 从已准入原 canonical 范围扩到相交完整原句的最小范围，整个映射不可拆分。窗口使用独立派生政策，不改变现有持久句段 payload；原句核心同时保留。候选池优先保护不同原 canonical 窗口和明确国别的官方来源窗口，再轮转原分支，抑制同一引文大量变体挤走其他证据。
5. 多问句仅在明确独立主题时生成最多三个本地视图；原请求及其准入始终保留。前置条件、省略主语、比较依赖、关系从句和“是否意味着”依赖不清时回退完整原问，不用模型补主语。语言明确时，汉字原件用汉字原问，拉丁原件用已有本地译文；混合或未知脚本保守保留视图。各视图独立排名，以原 RRF 常量融合，每组按实际可用视图数归一，不让未知文本因双票获额外优势。所有语言视图先共享最多 192 组候选池；每条语言路径继承共同池，仍做完整准入和原文校验，避免二次裁剪丢失同几何代表的强召回资格。共同池与语言路径的计数分别记录；scored_pair_count指查询与证据组的成功配对数，不等于推理分窗数量，后者由每组window_count另行记录。当前质量候选还将原检索 RRF 与模型相关性 RRF 等权融合，保留原件召回视图；原常量和准入阈值不变，质量收益待全量验证。
6. 累计重排时限从读取原文前开始，原问、译文、各子问共用 30 秒绝对 deadline。校验、锁、加载、分窗、排序、评分和最终发布均检查；超时清空成功标识、排名与子问种子。原生初始化只能前后检查，不能在线程内硬中断；不能声称所有阶段均有硬墙钟截止。推理批次配置终止计时器。按实际 token 长度组批降低 padding，保持全部窗口和输出所属候选不变。
7. 单问的原 canonical 首位完整窗口是软偏好，不是新增必要组。先独立保留完全不受偏好剪枝影响的原硬规划，再尝试偏好方案。偏好方案只有覆盖原方案每个具体硬token才可替换，不能只比较数量；失败回到原硬方案。再在剩余预算中、可选邻句之前保留该窗口；偏好不足时整组跳过并记 preferred_budget_exceeded，不把它算成必需证据缺口。仅允许实际已评分、原件完整合法的一个窗口。独立复查指出上一版本把该窗口列作硬种子可能挤掉原费用/流动性要求，已按通用预算反例修改。随后67合法组反例证明中间beam剪枝仍可能回退硬覆盖，故又增加独立硬方案保护与preference_plan_fallback，policy/2；两条beam各保持128/32原上限，不承诺全局最优覆盖。偏好计数与超时清空同步更新。

8. 同一完整几何范围、同一原件边界和全部引文映射的等价表示，共享各实际原检索分支的最佳真实排名，每分支只计一票。原rank_positions和canonical_anchor_rank保持；只有经canonical_rows完整证明且raw boundary可按现有两种producer格式重算的合法完整核心可以共享。未知元数据、拒绝组和不同范围不借票。policy canonical-sentence-exact-geometry-original-rrf/1；规划器新增10项反例后52项通过，独立64项检查通过。它只修复表示丢票，不承诺复制候选对其他competition rank无影响。helper /4新增固定公共ID/整数排名诊断，记录原RRF和各真实成功查询视图位置，避免把融合后的位置误说成模型排名。

9. 候选池的同版本、同实际rank桶内，仅在sentence_core/context_core/canonical_sentence_window原槽位中优先完整自然原句；required_context等其他类型原位，跨文档排序沿用旧最小rank桶的最小gid，避免桶内修复反馈到不同文档竞争。原top16/top32与192上限、既有窗口配额、几何去重与完整原件校验保持。policy升为scope-core-tie-batch-v5；真实producer的单canonical67原句/131合法上下文反例，原来漏7段，修复后67/67进入192池；相关129项合成检查通过，另由独立agent复验164项现有合成检查与66项独立断言，禁止I/O尝试0、未发现新增局部阻断；剩余容量有限时不承诺全部合法core必入。model manifest仅本地refresh，6资产字节不动、显式网络请求0。

## 字段语义的金融边界

field_semantics.py 登记原键、公开标签、含义、适用来源、产品类型依据、证据要求及禁止推断。现有微众目录 publish 只证明“发行机构”；不能证明管理人、销售机构或托管人。尚无独立登记来源的角色按产品保留 unsupported_semantic_role；引用费率说明不证明客户数值费率、当前可售或交易资格。匹配到另一产品、份额或版本不能支持当前对象。

consumer 与 boundary 使用同一窄合同并分别重算支持。知识工具专用公开 hash 保留只认成功原件合同，排除当前已知私有标记/身份，不放宽其他工具的一般脱敏规则。新合同的本地测试不等于最终云端模型遵守每条事实约束。

## 本地技术与开源依据

句段索引保留 structure_releases、structure_vector_releases、structure_vectors 三张派生表；查询重算单位合同并核验清单、同文绑定、向量 profile、dimension、连续窗口、有限值和范数。固定模型按各自空间排序，不比较不同模型余弦值；单分支故障保留词项召回并报告原因。缺少/损坏派生索引按原安全路径回退。

层级检索借鉴 Haystack 的小节点召回、父节点回取思路，未复制实现或引入完整框架：[官方说明](https://docs.haystack.deepset.ai/docs/automergingretriever)、[Apache-2.0 许可证](https://github.com/deepset-ai/haystack/blob/main/LICENSE)。

小型排序器采用 [官方 mMARCO MiniLMv2 Cross-Encoder](https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1)，Apache-2.0，固定 revision 1427fd652930e4ba29e8149678df786c240d8825。ARM64 Q8 六个固定资产合计 135706520 字节，复用现有 ONNX Runtime 与 tokenizers，没有安装 Torch。采用 [Retrieve & Re-Rank](https://www.sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html) 两阶段检索思路，单原始 logit 只作相关性顺序，不当概率或金融置信度。模型卡说明训练使用机器翻译的 mMARCO，不能据此假定任意跨语言金融术语都正确；脚本语言对齐是本轮待真实回归的工程选择。

仅 scripts/provision_reranker.py 的显式 provision 可以下载固定官方公开文件；查询时只读本地目录，逐次校验固定字节。缺依赖、缺模型、manifest/pin 失配和超时返回固定失败原因，不静默使用其他模型。本地更新 policy manifest 不重复下载模型。

明确国别软召回从现有机构登记的 publisher + 官方域名得到来源 country 元数据，只给已准入完整窗口增加一个候选视图；不新增/删除引文，不依据“美国”猜出美联储身份或央行角色。未知国家/未登记来源保留原路径，不把来源覆盖当作结论依据。
