# Navren 初版发布记录（2026-10-07）

本版为当前主源码与已完成功能的仓库快照，保留现有 UI 定稿。此次新增修改围绕独立财务库接入：账户首页、银行卡与所属账户详情、持仓/其他资产、保险/合同、分页流水、月报、财务日历与“我的”资料。保额和授信不计资产，共享账户不按卡重复汇总；历史数据只读，操作账本仍走原确认路径。

## 数据与入口

四演示主体：A市首富、种粮大户、坚持上班的包租婆、退休后重新创业的阿姨。合成历史覆盖 2016-10-04 至 2026-10-03，数据结构包括账户、卡片、授信、合同、持仓、保单、资产、义务与流水。所有个人历史、估值与保费均为合成演示数据，不代表真实银行客户、真实产品净值或银行到账。

本机实际启用入口仍为 `http://127.0.0.1:60291/`。新的启动脚本 `scripts/serve_financial_frontend.py` 复用原登录、银行、个人加密与知识库，启用 `NAVREN_FINANCIAL_DB`。这个脚本默认路径用于当前本机已有运行状态；新机器应明确配置自己的状态目录和数据库，不能复制本机身份/认证数据库或密钥。

## 重建合成历史

仓库发布生成程序和固定画像输入，不发布本机运行数据库。新库文件必须存在后才能启用，读取失败不会以空库或旧余额补位。

```sh
python3 scripts/generate_contest_finances.py --output outputs/contest-finances
python3 scripts/build_financial_database.py --source outputs/contest-finances/financial_data.sqlite3 --profiles simulated_bank/fixtures/contest_profiles.json --output outputs/financial-data/navren-financial-v2.sqlite3
python3 -m venv outputs/financial-mcp/venv
outputs/financial-mcp/venv/bin/python -m pip install -r financial_mcp/requirements.txt
```

生成命令拒绝覆盖已经存在的版本文件。首次创建与已有库升级分开操作，实际版本以生成回执为准。四账户操作账本的离线初始化使用 `scripts/initialize_demo_accounts.py`；主应用的同源读接口为 `/api/finance/data/presentation`，`view` 支持 `overview`、`month_report` 和 `calendar`。MCP 工具与宿主配置见 `financial_mcp/README.md`；主体绑定从登录身份取得，不能由模型指定。

## UI 与运行范围

保留当前页面组织、样式、登录页、昵称设置和已隐藏的账户切换条。只增加新数据需要的内容、详情路由与取数保护。正式欢迎页面源文件位于 `outputs/welcome-scene/index.html`，该单个 HTML 作为静态源随本版保留；其他 `outputs/` 运行产物不发布。

当前本机模型路由使用 AiPing，密钥通过环境变量/本机统一加载器注入，不写前端或仓库。服务器尚未部署；后续迁移需要把状态目录、数据库、密钥注入、HTTPS/反向代理与定期市场任务一同配置。仓库推送不等于服务器发布。

## 本轮完成依据

原 Chrome 登录会话实际打开新资产总览、银行卡详情、“我的”资料、保险档案和保单详情；保单可以关联缴费账户。总资产与新库历史快照一致。此次没有付费模型请求或全站测试。月报与日历的有界数据/界面检查使用相关执行窗口的交付记录；不据此声明所有页面、实际金融操作或生产环境均已验收。
