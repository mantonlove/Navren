请在 /Users/manton/CC/projects/Navren 落实以下任务。先读本目录 00-总控与接口合同.md，确认适用指令、当前代码及文件交接。交付界面改动与可核验结果。

## 目标与范围

让用户从对话理解并完成任务，再通过账户、发现和我的查看同一对象。沿用对话第一、账户、发现、我的的顺序；保留四域图谱、日历收益、每日六条封面流及30天历史，不重开导航和视觉方向。

负责 HTML、CSS、前端 JS、组件和前端 API 适配。使用已有后端金融结果、证据和状态，不在浏览器另算收益、余额、资格或可投资金，不用 localStorage 假装业务保存成功。

## 先做

1. 核对现有页面组织、i18n、日历、图谱、市场封面流、历史页和对话组件的真实状态。记录已完成部分，避免照旧方案重做。
2. 优先接收基座的账户目录/切换合同；在对话进入位置提供紧凑、清楚的四账户选择，不新增人物故事。切换前有录音、播报或未确认操作时给予明确处理反馈，切换后重新核对身份。
3. 建立同一任务的显示顺序：简短结论→关键金额/安排→可展开依据→必要动作。复用现有确认组件与回执，重要条件直接可见，辅助说明进入标题旁问号。
4. 让账户、发现、我的和对话通过稳定对象ID进入同一详情；保留来源/期间/版本。查看详情、拖动、文字选择、收藏和动作点击互不干扰。

## 再做

- 日历：分别展示投资损益、收支和生活事项；盈利暖红、亏损青绿、已计算零值灰，未知和缺数据单独标识且不补零。颜色配合正负号/文字，点击日期可查看全部事项、计算依据和来源。利润展示不把到账和估值变化混为一类。
- 图谱：保留日常收支、财富结构、目标与责任、偏好与认知；大小表达该视图定义的量，颜色表达类型/状态，线粗表达同一单位下的关系程度。显示图例，缺失值不画成零；不得让连接线看起来像未经证明的因果。
- 市场：保留真实邻卡及左右连续切换，最多六条；底部导航居中、历史入口同一行右侧。英文、大字号或窄屏放不下时，历史入口换至下一行靠右，导航仍居中，禁止缩字、裁字和重叠。历史按日期与类型筛选，归档缺失准确显示，不制造30天内容。
- 双语：静态与动态组件完整覆盖语言设置，初始化先确定语言，切页不先显示另一语言。新闻原文、官方名称和用户输入有来源标识，不改写成翻译后的官方原件。
- 经典、青春、关怀模式共用业务语义；键盘、触摸、大字号、减少动态模式都可完成任务。危险动作的条件与确认不能因“少按钮”隐藏。
