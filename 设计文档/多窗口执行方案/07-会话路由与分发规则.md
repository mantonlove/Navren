## 每次分发流程

1. 保存用户批准的方案及版本；读取目标近期任务、现有交付和协作范围，先排除重复实施。
2. 按任务实际涉及的模块派给对应会话；只向必要的窗口发送。跨模块任务指定一个总负责窗口，其他窗口接收明确接口任务。
3. 消息写明任务编号、批准方案绝对路径、具体目标、唯一写入范围、保留的既有改动、前置接口、交付物与验收标准。欢迎页相关改动交给专门会话，主 UI 不同时改其场景文件。
4. 使用 Codex 原生 send_message_to_thread 投递到上述 ID。当前文件持有者优先，最终职责归属不能代替实际交接。正在执行的任务按接口增量衔接，避免要求中断或覆盖原任务。
5. 记录实际投递对象和工具结果；读取会话进展与交付文件核验。已接收只代表投递成功，模块通过与集成通过分开报告。
6. 本会话汇总分工和已核验结果；跨模块失败返回具体文件负责人处理，由「集成验收」统一核验联合版本。

服务发布与重启仍按总控合同协调。此授权不自动扩大到新建会话、重排侧栏或无关外部消息。
