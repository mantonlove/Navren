# Navren

Navren 是一个财富顾问 Agent 原型：读取账户和账单，比较产品，解释风险与资金安排，并将可执行的建议交给用户确认。

本仓库包含前端、Agent、模拟银行、完整客户数据结构、演示样本和测试。当前银行功能使用自建模拟账户；没有接入真实银行或比赛官方接口。原项目名为轻舟（Qingzhou）。

## 运行

需要 Python 3.10 或以上版本。前端使用原生 HTML、CSS 和 JavaScript，无需构建。

```sh
git clone https://github.com/mantonlove/Navren.git
cd Navren
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --help
```

公开启动命令 `server.py` 与 `scripts/serve_financial_frontend.py` 使用同一套注册欢迎入口。默认打开 <http://127.0.0.1:60291>，内部业务服务使用独立的本机端口；匿名请求不能建立银行空间或读取私人数据。

运行前需准备已有的注册状态目录、封存的四份合成财务模板、市场库及对应加密密钥。状态目录包含 `ordinary-auth.sqlite3`、`ordinary-bank.sqlite3`、`ordinary-bank.personal.sqlite3`、`ordinary-knowledge.sqlite3`；继续使用已有数据时必须沿用其加密密钥。缺少数据库、密钥或依赖时启动会停止，不能退回匿名演示空间。

在已通过系统密钥管理器或部署环境注入凭据的终端中，使用自己的已初始化目录，例如：

```sh
.venv/bin/python server.py \
  --state-dir ./outputs/local-state \
  --financial-database ./outputs/local-data/navren-financial.sqlite3 \
  --market-database ./outputs/local-data/market.sqlite3 \
  --runtime-dir ./outputs/local-runtime
```

上例路径是部署参数，需要指向实际准备的数据库。`--prepare` 只核对配置和已有数据，不启动服务；`--port` 与 `--upstream-port` 可指定两个不同的本机端口。运行收据和调用记录写入 `--runtime-dir`，独立验收实例应使用独立目录。

用户先用手机号注册并完成短信验证，之后可用手机号密码或短信验证码登录。选定体验画像后，服务端为已验证账号绑定私有实例；不同账号选择同一个画像仍有各自的数据，同一账号重新登录可恢复自己的画像与历史。模板中的演示金额和人物资料均为合成数据。

Agent 主模型和 GLM 独立审核经 AI Ping 调用；语音由后端使用已配置的本地或云端服务处理。配置名称如下，密钥值应由密钥管理器提供，不写入仓库、文档或浏览器：

| 变量 | 用途 |
|---|---|
| `NAVREN_PORT` | 欢迎入口端口，默认 60291；显式 `--port` 优先 |
| `NAVREN_PERSONAL_DATA_KEY` | 现有个人库及聊天媒体原件使用的加密密钥，恢复时必须保持一致 |
| `AIPING_API_KEY` | Agent 主模型、GLM 审核及市场编辑的 AI Ping 凭据 |
| `NAVREN_SMS_CONFIG` | 服务端短信通道配置文件路径；注册需要已配置的短信服务 |
| `DASHSCOPE_API_KEY` | 百炼语音密钥；macOS 缺失时读取钥匙串 `CC/DASHSCOPE_API_KEY` |
| `DASHSCOPE_API_HOST` | 可选，北京地域业务空间专属域名 |
| `DASHSCOPE_WORKSPACE_ID` | 可选，未提供 API Host 时用于组成北京地域域名 |

内部 `create_server()` 工厂继续保留隔离工程测试的旧模式兼容性；公开命令通过注册启动器固定使用注册模式。旧浏览器缓存不会自动被认领为当前账号的数据，迁移必须能够核实归属。

## 语音

浏览器通过同源 `/api/speech/ws` 连接后端，使用服务端显式配置的本地或云端语音服务。启用百炼时，语音识别使用 `qwen-audio-3.1-asr-flash-streaming`，语音合成使用 `qwen-audio-3.1-tts-flash`；浏览器不会取得百炼密钥。没有提供业务空间域名时使用官方保留的 `dashscope.aliyuncs.com` 兼容地址。专属域名也可写入被 Git 忽略的 `voice.local.json`，格式为 `{"api_host":"业务空间ID.cn-beijing.maas.aliyuncs.com"}`，其中不能写密钥。

点击聊天页麦克风并授权后，可实时看到转写；再次点击结束时，直接发送一条可回放的语音消息，点击“查看文字”展开转写。转写交给统一 Agent，不再重复添加文字用户消息。按 Esc 取消。录音最多一分钟，ASR 使用单声道 16kHz PCM16，TTS 使用 24kHz PCM 流；离开页面停止录音和播放。只有最后一条 AI 回复显示朗读控制，停止后使用带斜杠的扬声器图标。语音不会自动确认资金操作。

本人发送的图片和语音原件由服务端加密保存，绑定到已验证账号及其体验工作区。浏览器缓存用于加快显示；清除站点缓存后，使用同一账号登录并恢复同一画像，可从服务端读回聊天与原件。保留数据库及原加密密钥后重启也可恢复。图片保存、音频回放与 Agent 使用语音转写文字分别按现有接口处理。

三种音色分别为龙安温 `longanwen_v3.1`、龙安洋 `longanyang_v3.1`、龙三叔 `longsanshu_v3.1`，聊天与设置页试听共用控制器。关怀版默认语速为 0.85 倍。接口使用已有同源会话、CSRF 和三十秒一次性票据，限制最多三项并发任务；语音只输入文字，不触发资金确认接口。语音失败会显示原因，不会静默换成另一种声音。

需要支持 AudioWorklet 的浏览器，并在本机地址或 HTTPS 下授予麦克风权限。当前服务仅监听本机地址；远程部署还需配置 HTTPS 与 WebSocket 反向代理，并保留注册认证链。

## 资金时间轴

`GET /api/finance/cashflow-timeline?days=90` 提供当前模拟账户的 1 至 365 天只读推演；默认 90 天。它将已确认现金承诺与周期续费／代扣候选分开展示，并保留每笔来源记录引用。待用户确认的草案、未确认操作、未确认收入、未记录日常支出及独立导入的 CSV 流水都不会被当成银行余额或支付事实。跨币种账户只按币种分别汇总；应急保留金额若无法唯一对应人民币主账户，会以未分配金额单独显示。该推演按日终净额计算，不代表交易日内的资金顺序。

`GET /api/finance/capabilities` 还会返回实际接入 `finance_agent` 的只读查询能力目录，包括数据范围和参数合同。对话路由按用户问题选用对应查询；目录不提供交易执行、用户确认或验证码工具，写操作仍走独立确认接口。

## 页面和功能

| 页面 | 内容 |
|---|---|
| `index.html` | 欢迎页及阅读方式选择 |
| `chat.html` | 理财对话、账单分析、产品比较、操作准备 |
| `recommend.html` | 产品、配置建议与市场信息 |
| `account.html` | 模拟账户、转账与AA收款、定时转账、资金预留与服务预约、银行卡、订阅/代扣、流水报告及CSV导入 |
| `mine.html` | 阅读模式、字号、语音、个人档案、财务记忆与收藏 |
| `copilot.html` | 顾问工作台与客户交接信息 |

经典版、关怀版、青春版使用同一套 Navren 浅色主题：雾蓝与浅蓝灰表面、帆船蓝主色、少量海青点缀。三种模式共享品牌色系，以字号、间距和信息密度适配不同使用方式；颜色由语义令牌管理，后续深色主题可沿用同一色彩关系。页面与资源共用内容版本，静态响应禁止缓存；旧网址、模式切换、前进后退和重新打开标签页会核对当前版本。

「我的」页面提供本机财务记忆管理：默认关闭，仅保存用户主动填写的目标、已确认支出与偏好；支持查看、修改、逐条删除和启停，并可设置参考有效期。期限按模拟业务日期计算；到期记忆仍可查看和修改，但不再进入分析。启用后，仅已接入的资金时间轴查询会参考对应类别，并显示来源卡片；不会推断正式风险等级或改动账户计算。密码、验证码、证件号、手机号和银行卡号不会被接受。

已接入模拟业务包括账单分析、理财申购／赎回、即时及定时转账、AA请求与模拟收款、商户订阅取消、银行代扣管理、卡片交易控制/挂失/办卡/提额，以及跨场景资金预留和服务预约。转账、AA、订阅和预约只更新本机合成账本，不联系真实收款人、商户或服务商；办卡和提额按明确的模拟规则、在推进模拟日期后审核。写操作先展示对象与变更内容，再由用户确认；高风险操作另需模拟验证，结果可查询并幂等重放核验。取消商户订阅不会关闭银行代扣，关闭银行代扣也不会取消商户合同。真实银行接口和真实资金操作未接入。

账户页可下载CSV模板，预览并确认导入人民币流水。首版限1.5MB、5000条；支持收入、支出、退款和转账。预览十分钟失效，且只保存在本机服务内存中；服务重启后需重新选择文件并预览。错误或冲突会阻止整批提交，重复导入按流水号和规范化内容去重。导入数据存于与模拟银行余额、持仓、订单分离的表中；“账单数据来源”只切换分析报告，资产与理财操作仍标明为独立模拟账户。账单月份、分类、异常和周期扣费分析都注明覆盖范围，周期候选的确认仅保存本地判断。CSV 未提供方向信息的转账会标成“方向未提供”，不猜测流入或流出。

## 固定合成评测

执行 `./.venv/bin/python scripts/run_financial_eval.py`，运行固定的 12 项合成金融场景回归，并生成 `evaluation/results/latest.json`。评测覆盖账单口径、重复扣费候选、记忆纠正与过期、安全确认、产品适配、余额不足、取消、重复确认及超时恢复。报告记录工程断言结果；它不代表真实客户效果、模型准确率或比赛评分。

## 模拟银行及数据依据

模拟银行包含客户全档案、账户、流水、信用卡、贷款、保险、产品、适当性、授权及审计等结构。演示金额、交易和客户均为合成数据。

数据结构参考 Apache Fineract、IBM Synthetic Data Sets 和 Open Banking UK，固定来源版本、改编说明与许可证随仓库保留；这些来源不代表真实银行连接或机构认可。详见 [模拟银行说明](simulated_bank/README.md)、[第三方说明](simulated_bank/THIRD_PARTY_NOTICES.md)、[完整数据合同](simulated_bank/customer-contract.json) 和 [接口合同](simulated_bank/openapi.json)。

注册启动器通过同源 `/api/finance` 使用银行核心，无需另开模拟银行 HTTP 服务。

## 财务日历与对话组件

「账户 → 财务日历」提供月、周、日及待办视图。也可直接在对话问“上周每天收支如何”“下个月要缴什么费用”，由当前 DeepSeek 原生工具和独立 GLM 审核产生同一套可交互日历。创建、修改、删除事件先准备确认卡；聊天文字不执行变更。旧卡保留生成时快照，点击日期读取最新详情；确认状态由后端读取，跨账户隐藏私人快照。

对话是所有功能的统一入口。后续增加业务时，必须同步提供同源查询/草案能力、原生工具描述、必要技能说明和一条真实聊天验收路径；不能只加一个独立页面。数据缺失时在对话说明缺失原因，办理仍沿用审核和用户确认链。

生活事件支持公历单次/每周/每月/每年、无效日期跳过或月末、仅这次/这次及以后/整个系列修改、计划预算和站内提醒。`outputs/calendar-acceptance/生活事件模板.csv` 提供中文模板；UTF-8、1.5MB、1000行，预览10分钟有效，错误或冲突整批阻止提交，重复导入幂等。流水仍使用已有账单导入入口，模拟与导入来源分别汇总。所有表自动原位新增，无须重置数据库。

已记录现金流、确认待付、候选、用户计划和投资损益分别显示；不同币种不相加。生日预算不扣款、不自动授予转账权限。用户明确纳入资金规划时，`calendar_budget_scenario` 按有效承诺/生效预留引用去重计算情景。缺少期初/期末净值、持仓数量、完整交易或成本时显示不可计算；原本金持仓未被伪造为每日收益。完整模拟估值只用于隔离验收，未接真实收益报价。

验证：`.venv/bin/python -m unittest discover -s tests`；`node --test tests/test_voice_frontend.js tests/test_api_response.js`；`.venv/bin/python scripts/verify_calendar_acceptance.py`。实施记录见 `设计文档/Navren财务日历实施与验收记录.md`，独立对账、真实模型摘要和界面截图位于 `outputs/calendar-acceptance/`。站内提醒仅在应用打开或查询时检查，未接后台推送、农历转换、设备日历或真实银行资金。


## 市场热点与市场周报

`market_sources.py` 采集白名单原文，`market_content.py` 使用独立公开数据库，`market_editor.py` 经程序证据检查与 GLM 审核发布 DeepSeek 草稿。原文日期、指标期间、生效日、检查时间分别保存；旧静态样例仅保留在 `examples/legacy-market/`，不参与页面或问答。原文变更/撤稿会使相关内容失效；超时不把旧消息改日期重新发布。

页面提供原文、独立解读、收藏、完整周报、历史期号和对象关联问答。用户要求的来源覆盖/更新状态区已移除，原文引用保留；接入状态仍可通过 `market_status` 在对话查询。本地依据见 `knowledge/market-provenance.md`。

公开资讯刷新：通过统一密钥加载器执行 `.venv/bin/python scripts/refresh_market.py --backfill-weeks 2`。`market_schedule.py` 分开调度热点（北京时间每日08:30、12:30、18:30）与周报（周一08:30，上一完整自然周）；失败后15、30分钟重试，每个热点时段最多3次，周报未完成则次日08:30补跑。本机 `com.manton.navren.market` 每5分钟检查是否到期，另在三个固定时段触发；应用后台每分钟检查，共用进程锁并在拿锁后复核是否仍然到期。更新安装：`.venv/bin/python scripts/install_market_refresh.py`。需要本机登录、网络可用，恢复运行后补跑，关机期间无法采集。

页面可见时每5分钟读取新版本，回到页面也刷新，未改变的周报不重建DOM，热点保持当前卡片。周报封面采用摘要与编号目录布局；手机与关怀版上下排版，完整阅读支持目录直达、文末原文去重和对象问答。`market_status.schedule.streams` 分别返回检查结果、最近成功和下一检查时间；来源状态区仍保留在本地知识库与对话中。检查证据：`.venv/bin/python scripts/audit_market_evidence.py`。付费媒体未获授权的正文、连续价格收益数据、真实用户收益与外部提醒推送未接入。详见 `设计文档/Navren市场定期更新与周报卡片实施记录.md`。

## 个人财务知识图谱

`financial_graph.py` 将实际记录、完整证据引用、程序计算、本人确认分配与独立情景分层保存，NetworkX 检索有界子图。五个问题视图为资金去向、成本价值、目标取舍、未来流动性和共同风险；资料入口保留完整检索。二维为默认，三维为可选探索；节点常显文字，金额按面积映射并按存量/期间、类型、币种分组，金额排序和日期时间轴辅助精确阅读。

节点、关系、洞察可直接问 Navren；原记录只读查询按会话隔离。当前与相邻期间输入可重算，退款按到账期，本金及内部转账不当消费；导入账单不混入演示银行资产。本人规划分配不冻结账户，推演不执行赎回/付款；锁定持仓不自动成为到账资金。删除或修正资料清除派生图及旧模型对话上下文，正在处理的旧版本答复失效。

共同风险缺少行业、底层权重或合同条款时只说明缺口，不生成损失；通用概念保存在 `knowledge/financial-concepts.json`，与个人暴露分开。普通预设名称移除“模拟”，真实资金边界和用户原话保留。详见 `设计文档/Navren个人财务知识图谱实施与验收记录.md`。
