# Navren

Navren 是用于比赛展示与技术验证的财富顾问 Agent 原型。它围绕账户、账单、公开产品资料和资金规划提供查询、解释与操作草案，帮助用户看清数据依据并核对拟办理事项。

当前项目处于开发阶段，不开展真实金融业务。仓库尚未发布公网体验地址；下文的运行步骤是在使用者自己的电脑上启动实例，不是作者电脑的访问入口。

## 功能范围

- 账户与账单：查看演示账户、交易记录及收支分析，支持独立导入 CSV 账单。
- 对话助手：根据问题调用已接入的查询工具与技能，读取依据、解释结果并准备受限操作草案。
- 资金规划：财务日历、资金预留、现金流推演及个人财务图谱。
- 产品与市场研究：读取公开披露资料，提供来源、日期和可获得的产品信息，以及市场精选和周报。
- 演示业务：转账、AA 收款、申购与赎回等由演示账务服务处理，办理前展示核对信息，结果保留操作记录。

页面与工具的覆盖范围以当前代码和对应验证为准。计划文档、历史测试报告及本机尚未提交的改动不代表本版本已经实现或验收通过。

## 数据与资金边界

| 数据类型 | 用途与边界 |
|---|---|
| 演示客户、账户及交易 | 人工构建的体验数据；不来自真实用户账户，不发生真实资金划转 |
| 用户导入的 CSV 账单 | 独立用于账单分析，不自动改变演示账户的余额或持仓 |
| 公开产品、政策及市场资料 | 保留出处与资料日期；披露目录不等于实时可购买清单，历史表现不等于保证收益 |

Navren 没有接入真实银行、支付平台或证券账户的资金接口，也不会联系真实收款人或商户。模型生成草案及独立复核不构成执行授权；金融变更须由用户通过独立确认流程办理。

## 在自己的电脑上运行

需要 Python 3.10 或以上版本。前端使用 HTML、CSS 与 JavaScript，无需单独构建。以下命令适用于 macOS 或 Linux，并要求已获得仓库访问权限：

```sh
git clone https://github.com/mantonlove/Navren.git
cd Navren
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

启动后，按终端打印的地址在同一台电脑的浏览器中打开页面。基础服务默认仅监听本机回环地址；服务器部署还需要独立配置访问入口、HTTPS、鉴权和反向代理。

基础启动会创建演示账务环境。四个体验画像所使用的独立财务数据库需要另行构建并接入，不能把基础启动与已经配置好数据的完整体验等同。

后端配置使用环境变量。密钥由部署者自行提供，不写入前端、仓库或命令示例。

| 变量 | 用途 |
|---|---|
| `NAVREN_PORT` | 基础服务监听端口 |
| `NAVREN_SIM_DB` | 演示账务 SQLite 数据库位置 |
| `NAVREN_PERSONAL_DATA_KEY` | 个人资料加密密钥；已有数据库重启时须使用原密钥 |
| `NAVREN_FINANCIAL_DB` | 已构建的独立财务数据库位置 |
| `AIPING_API_KEY` | AI Ping 模型调用凭据 |
| `DASHSCOPE_API_KEY` | 百炼语音服务凭据 |
| `DASHSCOPE_API_HOST` | 语音服务的业务空间域名，按服务商配置填写 |

未配置模型凭据时，需要模型参与的对话无法完整运行；语音还需要相应凭据、浏览器支持和麦克风权限。当前主对话链不解析聊天图片。独立财务库和只读 MCP 的安装、主体绑定及配置前提见 [财务 MCP 说明](financial_mcp/README.md)。

## 验证与说明

仓库保留银行、权限隔离、确认流程、账务幂等及 Agent 等专项测试。可按需运行对应测试，也可执行 Python 测试入口：

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
```

部分集成测试需要额外数据、模型配置或运行环境。列出测试命令不表示全部测试已在本次发布中执行；旧版量表、评分与测试记录也不表示当前模型准确率、真实客户效果或比赛成绩。运行生成的数据库、日志、截图和本机验收材料不随仓库发布。

当前架构与接入边界见 [技术说明](TECHNICAL.md)。演示银行的数据结构、来源与授权见 [银行说明](simulated_bank/README.md)、[第三方材料说明](simulated_bank/THIRD_PARTY_NOTICES.md) 和 [数据合同](simulated_bank/customer-contract.json)。
