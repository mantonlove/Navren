# 规划情景检查

每个方案保留账户、币种、起止日、原始目标及来源版本。相对日期由业务工具解析；市场真实时钟不能替代模拟业务日。

去重和时间顺序：

- 先不带 reserves 读取预算承诺，再用本轮真实 evidence_id 关联留款；空 commitment_ids 是全新事项，不能表示已有款项。同一付款必须有效引用去重，不能靠商户名称猜关联。
- saved_minor、本人目标分配、银行预留是不同状态；规划分配不冻结现金。
- 已确认应付、周期候选、用户生活预算分别列示；候选不能变成必然扣款。
- 持仓解锁、赎回确认与资金到账分开；未到期本金不能用于提前完成目标。
- 既定推演按后端日终口径，不能推断交易日内先后顺序或承诺日内绝不透支。

当用户只提供金额和期限、没有可核验收入或收益序列时，给出待核实条件与工具可计算的情景；不靠编造投资收益证明目标可达，不给“必定够用”的保证。

修改目标条件后重新取版本和情景。旧对话金额、旧截图与旧情景不成为新操作的资金依据。
