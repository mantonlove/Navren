# 持仓质量与核算检查

衍生方法来自 `portfolio-rebalance-review` 的持仓校验与目标对照；具体核算遵循 Navren 权益合同。

复核七类问题，指出它们影响哪项下游结论：

1. 时间：估值日期与实际持仓/组合生效期一致，期初期末是同一核算对象。
2. 数量级：大额异常是核查线索，不是模型可纠正的错误；不得擅自改数。
3. 聚合：账户、基金、日期与组合版本键唯一；不重复叠加基金和底层穿透对象。
4. 对账：完整部分之和与总额一致；局部已知金额不能冒充完整组合。
5. 完整性：成本、份额、现金流、分红/费用/企业行为缺项分别说明，不估值填空。
6. 新鲜度：低频与高频估值分别说明，截至日不同不能无说明地形成今日全景。
7. 重复：跨数据集账户、旧版本与新版本、现金与在途应收不重复计入。

当期损益、累计损益、已实现/未实现损益与现金到账是不同指标。比较需要同组合身份、币种、期间和核算口径；收益日历的净值间隔不等于每日可分配收益。

没有用户确认的目标和容忍区间时，不生成偏离百分比或“超过阈值”判断。不是任何投资都必须再平衡；产品锁定、渠道未知或费用未核验时，调整金额与可执行性保持待核实。
