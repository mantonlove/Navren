# 诊断读取与条件清单

衍生方法来自 `prospect-intake` 的资料规范化与质量旗标；以下字段按 Navren 实际接入能力裁剪。

逐项保留来源、截至日、账户/数据集身份和是否完整：

- 现金：已结算余额、应急保留、已确认义务、生效预留；信用额度另列。
- 投资：本金、份额、市值、成本、锁定期、退出与到账条件。读不到某字段就标未知。
- 收支：工资/其他收入、消费、退款、借款、投资本金流转、内部转账；导入账单与模拟账本各自汇总。
- 负债/保障：已记录本金、应付款、到期日与实际条款；不得从产品类别猜利率、罚息或保障范围。
- 目标：金额、期限、优先级、可推迟程度和本人已确认的账户分配；不得将 saved_minor 当现金。
- 风险：本人亏损容忍陈述、收入稳定性与流动性责任、正式风险问卷结果分别表述。

关键检查：同一账户是否被两个来源重复覆盖；期间和币种是否一致；档案与流水有无冲突；未知外部资产是否被暗中当零；已观察行为是否被写成用户确认偏好。

用户输出只描述已知范围。若某缺项阻断某判断，说明“缺少什么 → 哪项暂不能判断 → 可先完成什么”，不要要求用户一次提供全部私人资料。
