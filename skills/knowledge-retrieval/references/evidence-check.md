# 检索证据核验

本参考衍生自 `search-strategy` 的查询拆解与 `knowledge-synthesis` 的逐项归因；Navren 增加产品身份、版本有效与云披露约束。

按“主体 → 产品/份额 → 渠道 → 条款 → 日期”构造查询。仅在不会丢失身份的前提下尝试别名或更宽关键词；不能为了得到答案去掉份额、渠道或效期要求。

对每个拟写事实核对：

- 是否是发行人/管理人/实际渠道的原始披露；二次摘要仅用于发现原文。
- 文档针对基金整体还是具体 A/C 等份额；名称相近不合并费率和代码。
- 管理人风险资料是否被误写为销售渠道风险评级；历史销售关系是否被误写为今日在售。
- 原始发布、生效、估值与检索时间是否分别保留；过期或修订版本是否已失效。
- 引用是否直接支持该句话，包括数字单位、限定对象、例外和退出条件；只看到标题时不能断言正文。
- 是否允许把返回内容送入当前云模型；私人资料、仅本地可用内容或许可不明片段不得由模型自行放行。

资料冲突时陈列冲突字段、各自来源和日期，不求平均、不按相似度投票。缺少有效主证据则保留待核实，说明它影响哪项结论。

输出只列用户判断需要的证据。不要输出内部 provider 配置、索引位置、调试路径或无关私人数据。
