# 服务器部署前必须同步 GitHub（2026年10月26日用户明确要求）

- 每次更改服务器上部署的代码、静态文件或配置前，必须先将对应变更提交并推送到 GitHub 仓库，并核对远端提交和待部署文件摘要。仅本地保存或 commit 不满足此要求；同步失败时停止服务器变更。
- 本次部署只采用已同步提交中的对应内容，部署回执记录仓库、分支、完整提交号、文件摘要与实际加载结果。GitHub 同步、服务器采用和业务验收分别记录，不能相互替代。
- 多会话共用工作区时只提交本次明确范围，协调唯一 Git 写入负责人；保留其他未提交改动。密钥值、用户数据、完整日志与原页证据不进入仓库；配置通过不含密钥的配置或可复现变更脚本同步。
- 可使用 `scripts/verify_github_deployment.py` 核对远端分支提交及提交内的部署清单。该检查必须在服务器变更前成功，随后仍须执行备份、精确文件比较、回滚保护与实际加载核验。
