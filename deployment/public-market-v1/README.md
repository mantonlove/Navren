# 公开市场只读投影

仅新增 `public_market_projection.py` 与四类 GET 路由，不开放原市场 API 或账户 API。投影通过 `mode=ro` / `query_only` 在同一只读事务内核发布、来源与撤稿。网关不向业务端传递调用者身份头，响应不缓存。

`live/` 是现网入口文件的精确部署载荷：以部署前读取的原件为基础，仅加入与标准源码相同的公开路由。它保留现网尚未与 main 相同的聊天、附件及会话行为，不作为标准源码替代品。`manifest.json` 明确部署目标、前件及载荷 SHA-256；标准 `server.py`、`welcome_auth.py` 不直接覆盖现网。

Nginx 仅为新前缀增加每 IP 每分钟 60 请求（突发 12）、全站每分钟 120 请求（突发 20）及全站 4 个处理中请求的上限，超额返回 429。原来源校验、认证路由和定时器保持原配置。`nginx/site.conf` 相对现网仅多一条 location 配置 include。

部署须在正常推送 main 并核对完整远端提交与文件摘要后执行：逐文件 CAS、保留原件、在无活动业务连接时受控停止/启动 Web、先 `nginx -t` 再 reload；失败恢复本次文件与原服务。不得迁移数据库、密钥或初始化账户。更新后分别回读业务端、网关及公网匿名响应，核具体日版与事件版本；HTTP 200 本身不表示六卡完整或原文可访问。

已在精确现网载荷与相同市场依赖上完成 13 项隔离投影/HTTP 检查，涵盖只读、白名单、身份头过滤、特殊来源绑定与撤稿。隔离检查不替代生产数据和页面验收。部署回执保留在本地项目交付目录，不将生产数据库或内部日志纳入仓库。
